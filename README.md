# Moonshot Couch

A gamepad-driven motorized couch. This repo combines every version of the couch software with full commit history.

| Folder | Version | Original repo |
| --- | --- | --- |
| `v1-initial/` | Initial version (Jan 2024) | kevintran-git/moonshot_couch |
| `v2-pi-snapshot/` | Untracked working copy from the Raspberry Pi (May 2024), the code V3 started from | none |
| `v3/` | Version 3 (2024–2025) | LSkaling/Moonshot-Couch-Version-3 |
| `v4/` | Version 4 (2025): Python backend + Electron frontend | jclin22009/motorized-couch-v4 |
| `v5/` | Version 5, current (2026): V4 with a USB joystick adapter that works with any joystick or gamepad | none |

Unmerged branches are kept as `v3/freespin`, `v4/advanced-turn` and `v4/better-control`.
